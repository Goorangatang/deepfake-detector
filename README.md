# Deepfake Detector

An end-to-end deepfake detection system built from scratch using a custom-trained neural network and a custom dataset to identify AI-generated and manipulated media.

## 🚀 Overview

This project is an AI-powered deepfake detection system designed to classify images as real or manipulated. The model was trained from scratch using a custom dataset and integrated into a web application for real-time predictions.

The goal of this project was to explore computer vision, deep learning, and the challenges of detecting synthetic media.

## 🧠 Features

- Custom-trained deep learning model
- Custom dataset preparation and training pipeline
- Image classification for real vs. fake media
- Web-based interface for uploading images and receiving predictions
- Model evaluation and performance tracking


## 📊 Model Performance

- Training Accuracy: 83%
- Validation Accuracy: 76%
- Dataset Size: 3000 images

## ⚙️ Technologies Used

- Python
- TensorFlow 
- OpenCV
- NumPy
- Machine Learning
- Computer Vision
